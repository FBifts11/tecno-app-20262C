Instructivo para incorporar Bootstrap al proyecto

  1. Acceder a la terminal y ejecutar npm install bootstrap@5.3.8
  2. En la carpeta node_modules buscar la carpeta bootstrap, desplegar la carpeta dist y luego css
  3. Dentro de css buscar el archivo bootstrap.min.css, clickear con el boton derecho y copiar ruta relativa
  4. Buscar la clave styles dentro del build en el archivo angular.json, y agregar la ruta copiara (va entre ""), de ser necesario reemplazar las \ por /
  5. Para incorporar JS: ir a la carpeta js dentro de dist y copiar la ruta relativa del archivo bootstrap.bundle.min.js
  6. Crear la clave scripts dentro del build del angular.json (a continuacion de styles), y agregar la ruta copiada (igual que antes, va entre "", y reempazando \ por / de ser necesario)
  7. Para utilizar los componentes de Bootstrap v5.3.8 ingresar en https://getbootstrap.com/docs/5.3/getting-started/introduction/
  8. Buscar la seccion componentes en el menu lateral izquierdo y seleccionar el que se va a utilizar
  9. Copiar el codigo htm en la plantilla del componente
